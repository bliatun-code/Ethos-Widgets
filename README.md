# Ethos Widgets

## VoltDeck

A full-screen battery, telemetry and power dashboard for FrSky ETHOS.

**Development build 2026.4-v2. Physical X20RS/model testing is in progress. No release or tag has been created.**

[Readable Lua source](scripts/VoltDeck/main.lua) | [License](LICENSE) | [Notices](NOTICE.md) | [Changelog](CHANGELOG.md)

## Install for testing

1. Download `main.lua` from the source link above.
2. Put it on the radio SD card as `scripts/VoltDeck/main.lua`.
3. Restart ETHOS and select **VoltDeck** in a full-screen widget area.
4. Configure sensors and battery capacity for the active model.

Upgrading from the experimental Batt-key build requires selecting VoltDeck again and reselecting its sensor sources.

## Configuration overview

- **Battery:** consumed mAh, capacity and cell count. Remaining charge = 100 * (capacity - consumed) / capacity, clamped to 0..100%. Reset consumption for a new pack.
- **Appearance:** radio theme, black or custom colors; reuse the selected model picture; native ETHOS fonts by default.
- **Lower deck:** custom telemetry, RPM, Watts, average cell voltage, RPM + Watts, or RPM + Watts + cell voltage. Choose Numeric or Retro LCD.
- **Motor / RPM:** measured RPM or an explicitly labelled KV-and-voltage estimate; manual or full-pack KV scale.
- **Battery alert:** selectable WAV and repeat interval at 30% or lower. Battery colors are green above 40%, yellow at 40%, orange at 35% and red at 30%.
- **Flight log:** optional model-specific counter, session summary and bounded RSSI/VFR history. Only the counter persists; last-flight graphs stay in RAM.

An illustrated English and Norwegian guide is being prepared with native simulator screenshots and clearly labelled synthetic examples. Those examples are not physical flight-test results.

## Safety and compatibility

Development target: **FrSky X20RS, ETHOS 26.1.2**. Other radio/firmware combinations are not confirmed. Keep native telemetry alarms, failsafe and pre-flight checks. An armed bench test can still qualify as a flight without a suitable airborne gate. Graph colors are visual thresholds, not native alarm settings.

Watts is electrical input power (V * A), not shaft power. Average cell voltage does not identify a weak individual cell. KV estimates are not measured shaft RPM.
